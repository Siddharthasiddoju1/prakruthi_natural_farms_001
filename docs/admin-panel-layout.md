# Admin Panel Layout

## Left Navigation
- Overview
- Products
- Pricing and Inventory
- Milk Subscriptions
- Orders
- Customers
- Delivery Areas
- Reports and Export

## Dashboard Widgets
- New Orders Today
- Active Milk Subscriptions
- Low Stock Alerts
- Pending Deliveries by Area
- Revenue Snapshot (Daily and Monthly)

## Core Admin Screens
- Product Management: add/edit product, images, tags, stock, pricing
- Subscription Management: active/paused plans, quantity edits, schedule updates
- Order Management: status progression (Placed -> Packed -> Out for Delivery -> Delivered)
- Customer Management: profile, addresses, recent activity
- Delivery Planner: morning routes, area filtering, CSV export
